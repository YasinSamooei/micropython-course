# 🚀 MicroPython Course

Welcome to the official repository of the **MicroPython Course**!  
Here you’ll find all the files, examples, and hands-on projects taught during the sessions.  
Instructor: **Yasin Samouei**

---

## 🎯 Course Goal
This course is designed for enthusiasts who want to learn **microcontroller programming** and step into the world of **IoT and Smart Homes**.  
We start from Python basics and gradually move into real-world projects.

---

## 📚 Sessions
- **Session 1: Python Basics + Boards Introduction**  
- **Session 2: Security Modules**  
- **Session 3: Monitoring / Smart Home Modules**

📄 [Download Full Course Outline](https://github.com/YasinSamooei/micropython-course/blob/main/%D8%AF%D9%88%D8%B1%D9%87%20%D9%85%DB%8C%DA%A9%D8%B1%D9%88%D9%BE%D8%A7%DB%8C%D8%AA%D9%88%D9%86%20-%20%DB%8C%D8%A7%D8%B3%DB%8C%D9%86%20%D8%B3%D9%85%D9%88%D8%B9%DB%8C/%D8%AF%D9%88%D8%B1%D9%87%20%D9%85%DB%8C%DA%A9%D8%B1%D9%88%D9%BE%D8%A7%DB%8C%D8%AA%D9%88%D9%86%20-%20%D8%B3%D8%B1%D9%81%D8%B5%D9%84%20%D9%87%D8%A7.pdf)

## 🛠 Requirements
- Install Python and Thonny IDE  
- Install USB drivers for ESP boards  
- Use esptool to flash firmware

## 🚦 Quick Start
```bash
git clone https://github.com/username/micropython-course.git

```
Run the codes on your board using **Thonny IDE**.
